# 产品需求

## 1. 定位

RDPilot 是 Windows 上的本地远程桌面连接管理器。

它解决的不是「如何建立远程控制通道」，而是「几十到几百台 RDP 主机如何被记住、分组、找到、
连上」。连接仍由 Windows 自带的 RDP 服务完成；RDPilot 不安装被控端、不搭建中继、
不做无人值守访问。

**与直接用 mstsc 的差别**

| 原生 mstsc 的体验 | RDPilot 的做法 |
|---|---|
| 每次手输 `IP:端口`，端口记不住 | 卡片化保存，一键连接，端口自动带上 |
| 历史只有下拉框里的 10 条，不能命名与分组 | 导入历史后可命名、分组、搜索、收藏 |
| 用户名每次重填 | 从注册表 `UsernameHint` 回填 |
| 不知道机器现在通不通 | TCP 探测，卡片上显示在线 / 离线 / 未知 |
| 多个会话散落在任务栏 | 独立会话窗口内用标签管理 |

**不是什么**

- 不是 ToDesk / RustDesk / TeamViewer 这类远控软件：没有被控端、没有中继、没有账号体系。
- 不是 Windows App / 微软远程桌面这类云客户端：本地优先，不登录、不联网校验。
- 不与 RDCMan / mRemoteNG 比条目数量：只做 RDP，把三种执行器的差异写清楚。

## 2. 目标用户

- Windows 下的 IT 运维、后端开发、驻场实施人员
- 日常管理 10–50 台主机，大量是内网地址与少量端口映射
- 高频使用，需要快速定位、批量查看状态、保存凭据

## 3. 核心场景

| # | 场景 | 需要满足 |
|---|---|---|
| S1 | 每天早上连公司开发机 | 常用主机可收藏并置顶；不需要每次搜索与输入端口 |
| S2 | 临时连客户现场机器 | 新建表单在三个字段内完成；连过一次后自动留下记录 |
| S3 | 管理一整片网段 | 按分组筛选；一屏内看到多台状态 |
| S4 | 只记得 IP 尾号 | 搜索同时匹配名称、地址、端口、用户名、备注 |
| S5 | 换电脑后立刻能用 | 首次启动扫描系统历史，一键导入并去重 |

## 4. 功能范围

### 4.1 连接管理

| ID | 需求 | 验收要点 |
|---|---|---|
| C-01 | 连接增删改查 | 字段：名称、地址、端口、用户名、域、分组、标签、备注、显示参数；名称留空时以地址兜底 |
| C-02 | 历史导入 | 读取 `HKCU\...\Terminal Server Client\Default\MRU*` 与 `Servers\<host>\UsernameHint`；`host:port` 拆分；去重；只补空字段 |
| C-03 | 布局 | 卡片单列 / 两列 / 三列、列表四种；选择持久化 |
| C-04 | 搜索 | 实时匹配名称、地址、端口、用户名、备注；无结果时提供「用该关键字新建」 |
| C-05 | 分组 | 创建、重命名、移动、删除；删除分组时连接回落到未分组 |
| C-06 | 视图 | 全部主机 / 收藏 / 最近连接 / 按分组筛选 |
| C-07 | 右键菜单 | 复制名称、地址、用户名、完整信息；分享文本；保存 `.rdp` |

### 4.2 连接与会话

| ID | 需求 | 验收要点 |
|---|---|---|
| S-01 | 三种执行器 | 内置 RdpHost（默认）、系统 mstsc、随包 FreeRDP；设置内切换，不支持项自动回落并提示 |
| S-02 | 内置多标签 | 同一窗口内多台主机；标签可关闭、可拖动；`+` 新建连接 |
| S-03 | 窗口行为 | 独立于主窗口；四边四角缩放；最大化后拖标题栏还原；`F11` 无边框全屏 |
| S-04 | 状态 | 连接中、已连接、未建立连接、已断开、失败；来源为宿主事件，不猜测 |
| S-05 | 探测 | TCP 探测三态；超时算未知；并发与缓存可配 |
| S-06 | 批量连接 | 并发 1–6、间隔、单批上限 200；失败项单独重试 |
| S-07 | 视频墙 | 多会话按网格铺在同一原生窗口；布局可保存 |

### 4.3 凭据与数据

| ID | 需求 | 验收要点 |
|---|---|---|
| D-01 | 密码保存 | 用户显式勾选后保存；DPAPI 密文；未勾选则只在本次连接使用 |
| D-02 | 密码传递 | 内置 / FreeRDP 经 stdin；mstsc 经 `.rdp` 密文；明文不落盘、不进命令行（`cmdkey` 兜底除外） |
| D-03 | 清除凭据 | 只清本应用记录，不改动 Windows 凭据管理器，并用提示说明 |
| D-04 | 备份 | 启动、清空、导入前生成；滚动保留 5 代；损坏文件另存 |
| D-05 | 导入导出 | 备份 JSON、`.rdp`、CSV / TSV、纯地址、分享文本；交换格式单向导出 |

### 4.4 界面与分发

| ID | 需求 | 验收要点 |
|---|---|---|
| U-01 | 主题 | 深色 / 浅色 / 跟随系统；切换即时生效 |
| U-02 | 语言 | 中文 / English，默认跟随系统；键与占位符对齐 |
| U-03 | 托盘 | 关闭到托盘可配置；托盘菜单含显示、最近连接、退出 |
| U-04 | 命令行 | `--list` / `--probe` / `--connect` / `--disconnect` / `--diagnose`；退出码 0–3 |
| U-05 | 安装 | NSIS 安装包与便携版；卸载不删数据；`.rdp` 关联可关闭 |

## 5. 信息架构

```

├─ 顶栏：搜索、排序、布局切换、新建连接
└─ 内容区：卡片或列表
   └─ 连接抽屉：基础、远程参数、凭据、高级

├─ 数据与备份
├─ 快捷键
└─ 关于

└─ 标签栏 + RDP 画面
```

## 6. 非功能要求

- **性能**：5000 条连接可滚动浏览；探测不阻塞 UI；首屏 1 秒内可用。
- **可靠**：任何一次写盘失败不能损坏既有数据；解析失败的条目隔离而不是整库丢弃。
- **隐私**：无遥测、无账号、无联网校验；日志与导出文件不含密码。
- **可访问性**：键盘可达；焦点可见；文本对比度不低于 4.5:1。
- **平台**：Windows 10 1809+ / Windows 11（x64）；不需要管理员权限。

## 7. 非目标

1. **不做被控端与中继**，不做无人值守访问。
2. **不实现 RDP 协议**，不接管系统凭据管理器。
3. **不做账号、云同步、团队共享**。
4. **不做密码管理器**：不生成、不审计、不跨机同步密码。
5. **不做自动更新与代码签名**（1.0.0 范围内）。
6. **不支持 Windows 以外的平台**：历史导入依赖注册表，凭据依赖 DPAPI。

## 8. 已知取舍

- 默认跳过远程主机身份验证：内网自签名证书常见，代价是中间人可冒充目标主机；
  公网环境建议开启。
- `cmdkey` 兜底会把明文放进子进程命令行：只在 DPAPI 失败时启用，无法从应用侧规避。
- mstsc 回退路径的状态依赖窗口标题：`tasklist` 被拦截时停在无状态，不猜测。
- 内置宿主与证书探测依赖 .NET Framework 4.8（Windows 10/11 自带）。

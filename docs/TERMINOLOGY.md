# 术语与对外口径（唯一真相源）

> 目的：避免 README、USAGE、SECURITY、设置页对同一件事各写一套长句。
> 其他文档只写一句结论并链接到本文件，细节在这里维护。

## 1. 核心术语

| 术语 | 定义 | 不要混用 |
|---|---|---|
| **连接** | 一条主机配置（地址、端口、用户名、显示/重定向选项） | 不叫“服务器”“主机”（主机指远程机器本身） |
| **分组** | 连接的组织容器，回答“在哪” | 不叫“文件夹”（UI 里可以借用文件夹图标） |
| **标签** | 连接的多值标记，回答“是什么” | 不叫“分类”“类别” |
| **环境** | `prod / staging / test / dev / none` 的固定语义 | 不用颜色标签代替环境语义 |
| **凭据** | 用户名 + 域 + 密码的组合 | “密码”只指密码本身；“登录信息”过于含糊 |
| **凭据库** | 可被多条连接引用的独立凭据对象 | 不叫“密码本”“账号库” |
| **会话** | 一次正在运行的远程桌面进程/窗口 | 不叫“连接”（连接是配置，会话是运行态） |
| **执行器** | 实际承载 RDP 的组件：内置宿主 / 系统 mstsc / FreeRDP | 不叫“引擎”“客户端”（客户端易与 Windows 远程桌面客户端混淆） |
| **内置宿主** | 随包的 `RdpHost.exe`，用系统 `mstscax.dll` 承载会话 | 不叫“内置 mstsc”“自研协议” |
| **探测** | 对 host:port 的 TCP 连通性检查 | 不叫“扫描”“Ping”（不保证 ICMP） |
| **健康** | 探测历史 + 延迟 + 证书到期的聚合视图 | 不叫“监控”（监控暗示后台常驻采集） |

## 2. 密码与凭据口径

1. 密码只以 Windows DPAPI（Electron `safeStorage`）密文写入 `credentials.json`；
   `data.json`、导出文件、分享文本、日志、审计日志都不含密码或密文。
2. 内置宿主与 FreeRDP 的密码只经管道送进子进程内存，不进命令行。
3. `cmdkey` 兜底会把明文短暂放进子进程命令行；默认关闭，开启需用户显式同意。
4. 清除凭据只删本应用记录，不改动 Windows 凭据管理器。
5. 换机后 DPAPI 密文不可解：连接仍可导入，密码需重输；迁移向导会列出
   `hasCredential=true` 的条目提醒。

## 3. 日志与审计口径

| 文件 | 内容 | 保留 |
|---|---|---|
| `logs/main.log` | 运行日志，写入前经 `logger.sanitize` 脱敏 | 2MB 轮转，保留一代 |
| `audit.log` | 写操作审计（连接/凭据/导入/恢复/设置重置），动作码 + 目标 id，无密码 | 默认 90 天、最多 20000 条 |
| `backups/rdpilot-*.json` | 独立定时备份，含连接/分组/模板/视图/设置，不含密码 | 默认 14 份 |
| `health-history.json` | 延迟/在线率采样，不含远程内容 | 24 小时滚动 |

提交 issue 前仍建议自行检查日志中的主机名与用户名；脱敏只覆盖密码类字段，
主机名是排障必需信息。

## 4. 版本与分发

- 版本号唯一展示位：主窗口顶栏品牌名旁。
- 安装包未签名：SmartScreen 会提示“未知发布者”，这是当前发布条件的限制，
  不是文件损坏。
- 数据目录：`%APPDATA%\rdpilot`（可用 `RDPILOT_USER_DATA` 覆盖，仅供测试）。

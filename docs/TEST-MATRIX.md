# 验证矩阵（环境 × 必测项）

> 最后核对：2026-10-28。
>
> 这份表解决的是"**本机全绿 ≠ 能用**"：`verify-*` 断言的是源码契约，界面冒烟跑的是本机单机，
> 而 RDP 产品的真实故障几乎都在环境差异里（域、网关、精简镜像、DPI、多屏）。
> 逐项勾选的主干道流程见 [`RELEASE-CHECKLIST.md`](RELEASE-CHECKLIST.md)。

## 0. 怎么用

1. 拿到一台机器，先在表 §1 里找到它对应的**环境档位**；
2. 按 §2 的"必测项 × 环境"交叉表执行；
3. 每一项的结果只写三种：**通过 / 失败（附日志片段）/ 未测（写明缺什么环境）**。
   **不许写"应该没问题"**——未测就是未测。

## 1. 环境档位

| 档位 | 操作系统 | 关键特征 | 为什么必须覆盖 |
|---|---|---|---|
| E1 | Windows 10 1809（LTSC 2019） | 老版 mstscax、旧 CredSSP 默认值 | 支持下限；新 API 在这里最容易缺 |
| E2 | Windows 10 22H2 | 主流存量 | 用户占比最高 |
| E3 | Windows 11 23H2+ | 新版 DWM、圆角、DPI 感知变化 | 高 DPI 与多屏问题集中在这里 |
| E4 | Windows Server 2019 / 2022（作**客户端**） | 无 Store、默认无 Media Feature Pack | 运维人员真实桌面 |
| E5 | 精简镜像（如 LTSC 裁剪 / 无远程桌面组件） | `mstscax.dll` 或 `mstsc.exe` 被移除 | 内置与 mstsc 双双不可用，只剩 FreeRDP |
| E6 | 域成员机（含 GPO 限制） | 组策略可能禁 `tasklist` / `reg` / 凭据委派 | 状态判定与历史导入会退化 |
| E7 | 虚拟机 / 无独立 GPU | 无硬件加速、无 3D | GPU 进程崩溃是高发问题（应用默认已关 GPU） |
| E8 | 高 DPI（125% / 150% / 200%）+ 多显示器（2–3 屏，混合 DPI） | 缩放与坐标换算 | 窗口尺寸、卡片布局、会话全屏的经典崩点 |

**目标端**（被连的机器，独立于上表）：Windows 10/11 专业版（开 RDP）、Server 2019/2022、
带 RD 网关的测试域、跳板机后的内网机、自签名证书主机、关闭 NLA 的主机。

| 日期 | 版本 | 环境档位 | 执行人 | 通过 / 失败 / 未测 | 备注（失败项编号 + 日志路径） |
|---|---|---|---|---|---|
| — | 1.0.0 | — | — | 未测 | 建立时只做了本机（E2/E3 近似）与契约层断言，**其余档位未测** |

> 填表纪律：一行只对应一台机器；同一档位多台机器分多行。
> "未测"必须写缺什么（没有域控 / 没有第二块屏 / 没有精简镜像），否则下一轮会重复踩。

## 4. 已知在这些环境里**不承诺**的行为

| 环境 | 不承诺什么 | 依据 |
|---|---|---|
| E5 精简镜像 | 内置宿主与 mstsc 都不可用；只有 FreeRDP 可能可用，且 FreeRDP 无打印机/摄像头/多屏 | `CAPABILITY-MATRIX.md` §2 |
| E6 域 + GPO | `tasklist`/`reg` 被禁时，状态停在 `idle`、历史导入不可用（有明确提示，不猜） | 已知限制 7、8 |
| E7 无 GPU | 已默认禁用硬件加速；若仍出现 `FATAL: GPU process isn't usable`，检查是否设了 `RDPILOT_ENABLE_GPU=1` | README 常见问题 |
| E8 混合 DPI | 会话窗口的全屏在混合 DPI 多屏下按系统行为，可能落在主屏而非"当前屏" | 主屏语义，未做按屏记忆 |
| 任意 | 探测 `unknown` 不等于连不上（防火墙 drop 探测包但放行 RDP） | `BEHAVIOR-MATRIX.md` §5 |

# RDPilot 使用说明

> 运行要求：Windows 10 1809+ / Windows 11（x64），不需要管理员权限，不需要 .NET 或额外运行时。
> 安装与企业部署见 [`INSTALL.md`](INSTALL.md)；脚本化调用（`--list` / `--probe` / `--connect`）见 [`CLI.md`](CLI.md)。

## 首次启动

第一次打开先显示欢迎页，顶部说明「这是什么 / 数据只在本地 / 怎么开始」，底部有三个入口：

- 「从 Windows 导入」：进入历史导入向导
- 「新建连接」：直接打开新建抽屉
- 「稍后」：关闭欢迎页，以后不再自动出现

从欢迎页进入导入向导后：

1. 向导自动扫描注册表，列出发现的记录，顶部显示「共发现 N 条记录，其中 M 条已存在」
2. 按需勾选，或用「全选 / 取消全选」批量选择
3. 默认勾选「按网段自动分组（推荐）」，会按 IP 前两段建组（如 `10.68 内网`、`公网`）
4. 点「导入 N 条」；不想现在导入就点「暂不导入，不再提示」——这个选择会被记住，以后不再自动弹出；需要时可在「设置 → 数据与备份 → 导入历史记录」手动打开

导入只新增连接信息，不涉及密码；已存在的条目只会补全空字段，不会覆盖你改过的名称、分组与收藏。

## 新建连接

点右上角「新建连接」，地址、用户名与密码都在首屏：

| 字段 | 必填 | 说明 |
|---|---|---|
| 地址 | 是 | 可粘贴 `IP:端口`，自动拆出端口；端口默认 3389 |
| 用户名 / 域 | 否 | 留空时由 Windows 凭据或连接时的登录框处理 |
| 密码 | 否 | 新建时「保存密码」默认开启：填了密码才会用 DPAPI 加密保存；关掉开关则只在本次连接使用、不落盘。编辑已有连接时开关如实显示「已有保存密码」，不改密码、不动开关就不会清掉它 |

名称、分组、颜色、备注和远程参数收在「更多设置」里（新建默认收起，编辑默认展开）：

| 字段 | 说明 |
|---|---|
| 名称 | 留空则以主机地址作为名称 |
| 分组、颜色标签、备注 | 备注参与搜索 |
| 远程参数 | 显示模式（全屏 / 窗口化 / 多显示器）、分辨率、色彩深度、声音 |

点「保存并连接」可直接发起连接。

## 会话窗口

设置 →「连接与会话」可选择三种 RDP 协议程序：

- **内置 RdpHost（默认）**：RDPilot 自己的窗口，使用 Windows 自带 RDP 控件；剪贴板、音频、
  多显示器、动态分辨率与系统远程桌面一致。没有保存密码时默认**继承当前 Windows 登录凭据**
  （CredSSP 免密）；有保存密码时仍用保存的密码。
- **系统 mstsc**：调用 Windows 自带客户端，兼容旧环境。
- **FreeRDP（随包）**：已随包分发 FreeRDP 3.32.2，不依赖系统 RDP 组件；需要连接里保存密码，
  Windows SSO 与“嵌进主窗口”的 B2 形态在下一阶段。当前是外部进程，窗口/Taskbar 归 FreeRDP 自己。

内置会话窗口是**独立窗口**：默认按工作区约 50% 打开、可自由缩放，连接期间主界面仍可操作；
同一窗口用浏览器式标签同时连多台，标签 `×` 关闭当前会话，标签条右侧 `+` 回主界面新建连接。
窗口无系统标题栏，`F11` 全屏时隐藏所有 chrome；顶部工具栏可重连 / 断开 / 缩放 / 全屏 / 退出。
任务栏默认只有 RDPilot 一个图标（设置里可改为会话窗口独立图标）；手动关闭会话窗口后，
主界面会立即显示为已断开，不会留下无法操作的「已连接」。
右键标签可以查看连接信息、调整连接速度、开关剪贴板/驱动器/打印机、切换音频，或打开
「编辑连接设置」。每条连接的剪贴板、驱动器（文件传输）、打印机也都能在编辑抽屉的远程参数里预设。
默认不再弹「无法验证远程计算机身份」确认框；需要严格校验证书时在设置里关闭「跳过身份验证警告」。

## 布局、排序与筛选

顶栏只负责搜索与切换布局（单列 / 两列 / 三列 / 列表），排序、筛选、密度在主机列表上方的**工具栏**里，全应用只有这一处。

- **单列**：卡片最宽，名称与用户名完整，适合逐台确认
- **两列**：信息量与可见台数平衡
- **三列**：一屏看到更多主机，适合 20 台以上扫状态；窗口变窄会自动降为两列、一列
- **列表**：表格形态，最左有 1、2、3… 序号，可点表头按 主机 / 地址 / 用户名 / 状态 / 最近连接
  排序，再点一次反向。**单击行只选中，双击行才连接**——避免只想看一眼时手一滑连到生产机。
  卡片与列表同一语义：单击选中、双击连接。

工具栏左侧是计数与筛选（全部 / 在线 / 离线 / 已连接 / 有凭据 / 未分组，可叠加），右侧是排序、升降序、密度（舒适 / 紧凑）与刷新连通性。搜索时计数变成「匹配 M / 共 N」，命中的名称、地址、用户名、备注都会高亮。

筛选、排序、方向、密度、布局与列显隐都会记住，下次打开沿用。窄窗口下工具栏会把次要筛选收进「筛选」菜单，不会把右侧按钮挤掉。

## 批量操作

列表形态没有复选框：单击选中一行、`Ctrl` 追加/取消、`Shift` 连选、`Space` 切换、
`Shift+↑/↓` 扩展；选中 ≥2 行后底部浮出操作条：**移动到分组 / 收藏 / 删除 / 取消**。
批量删除只弹一条提示，带一次「撤销」，撤销会把这一批全部恢复（分组、收藏、备注、凭据标记都保留）。

## 点卡片会发生什么

- **鼠标移到卡片/行上即高亮选中；单击保持选中；双击才连接**。已连接 / 连接中 / 未建立连接时双击也只选中，不会开出第二个窗口
- 卡片右侧：「连接」按钮（有会话时变「断开」），以及「⋯」更多菜单
- **名称 / IP / 用户名 / 地址文字都可以直接拖选，双击文字即可复制**（不会触发连接）
- 右键卡片/行：连接或断开、编辑、复制（名称 / IP / 地址+端口 / 用户名 / 完整信息）、
  分享（复制分享文本 / 保存 `.rdp`）、收藏、移动到分组、删除
- `⋯` 按钮和右键菜单是同一份动作；列表操作列也保留 `▸` + `⋯`
- 键盘：`Tab` 聚焦卡片，`Enter` 连接（显式动作），`Space` 只选中，`F2` 编辑，
  `Shift+F10` 或菜单键打开右键菜单；列表里 `↑` `↓` 换行

卡片黑色主标题优先显示计算机名：启动后会读取 RDP 服务器证书 CN（`CertProbe.exe`），
再回落 DNS PTR / NetBIOS；解析不到时直接显示 IP/域名，用户名只作为副行前缀。
副行统一是 `Administrator@198.51.100.110:3389` 形式，用户名和地址可分别双击复制，也可以手动改名。
在线/离线/延迟不再写成文字：图标右上角状态灯——绿=在线/已连接、黄=离线、
琥珀呼吸=连接中/探测中；列表状态列只在离线或连接态时附一句文字。

## 多标签会话与分享

- 同一台电脑上的多条会话在**一个 RDPilot 会话窗口**里以浏览器式标签打开，可以同时连多台；
  标签右侧 `×` 关闭当前会话，标签条右端 `+` 回到主界面新建连接（保存并连接后附加为新标签）；
  工具栏只剩 6 个动作按钮：`⋯` 更多 / 缩放 / 全屏 / 最小化 / 最大化 / 关闭
  （**重新连接、断开不在标题栏**，收在「更多」菜单与标签右键里，少两个误点面）；双击标题栏可最大化/还原
- 会话窗口是独立窗口，连接期间主界面仍可操作；`F11` 全屏，默认不全屏
- **标签就是浏览器标签**：拖动换位、拖出窗口撕成新窗口（要拖出窗口 48px 才会撕离，
  往画面里拖不会丢会话）、中键关闭、`Ctrl+W` 关当前、`Ctrl+1~9` 直达、滚轮横滚找标签、
  右键菜单可固定/在新窗口打开
- **窗口怎么移动**：抓顶栏最左侧的抓手（品牌图标 + 两列小点，鼠标变"移动"形状）拖即可；
  也可以拖顶栏空白处，或 **Ctrl+拖动标签**；**只剩一个标签时直接拖标签就是移动窗口**
  （浏览器也不许把最后一个标签撕出去）。松手时指针在屏幕上沿会最大化；
  全屏状态先按 `F11` 退出再拖
- **断线不会丢标签**：远端重启/网络抖动导致断开时，标签保留并显示「已断开」（琥珀点），
  点「更多」菜单里的「重新连接」或标签右键「重新连接」会在原标签里恢复；只有主动关闭标签才会结束会话
- **标签只显示连接质量**：标题 + 延迟（ms）+ 吞吐（kbps，10Mbps 以上写 Mbps）+ FPS
  （静态桌面为 0）；不再显示窗口尺寸/缩放。吞吐走 Windows TCP 统计，需要以管理员身份
  运行才会显示（拿不到就整格省略，不显示假数字）。
  标签初始宽度较紧凑，连接变多时统一变窄；到可读下限（放得下这三项指标）后改为横向滚动/「∨」溢出列表
- **画面保持原始比例**：默认按远端桌面的长宽比居中显示，窗口比例不一致时留黑边；
  点黑边或右键「保持原始比例」可切到「填满窗口」，再点同一菜单恢复
- **拖边缩放**：鼠标移到窗口最外侧会显示缩放箭头，四边/四角都可拖；拖动过程中不会反复闪屏，
  松手后一次性按新尺寸重协商
- **关闭确认**：设置 →「断开前确认」打开后，标签 `×`、`Ctrl+W`、全屏条 `×`、关闭整个会话窗口
  都会先确认（默认按钮是「否」）；主界面的「全部断开」仍然只问一次
- 启动时的「最大化」是真正的最大化（保留顶栏、露出任务栏）；需要无边框铺满请按 `F11` 或用全屏启动
- 右键列表空白处或工具栏文字：新建、从剪贴板导入、导入 Windows 历史、复制全部配置、
  导入/导出配置文件
- **分享**：右键单条连接 →「分享」→ 复制分享文本，粘到另一台 RDPilot 的「从剪贴板导入」
  即可；也可以保存为标准 `.rdp` 文件。分享内容与 `.rdp` 文件**都不含密码**，对方首次连接
  时会正常提示输入密码

## 密码与系统凭据

勾选「保存此密码（DPAPI 加密，仅本机可用）」并填密码后，密码加密存入
`%APPDATA%\rdpilot\credentials.json`；连接时把**密文**写进临时 `.rdp` 交给 mstsc，明文
任何时候都不落盘。再次编辑时会自动回填密码（默认显示为圆点），点输入框右侧的眼睛或
「查看密码」即可看明文；查看只发生在主窗口的编辑抽屉里，按需解密、关闭即清，没有批量
导出明文的接口。正常情况下**不会**写入 Windows 凭据管理器，只有本机加密失败时才回退写入一次。

这个不对称要记住：本应用**可能写**系统凭据（仅兜底），但**永远不删**，所以清理只能你手动做。
不删的原因不是偷懒：`TERMSRV/<host>` 这个条目名与你自己在 mstsc 里勾「记住我」存的是同一条，
分不清归属，删了会连带清掉你自己的凭据。

清除方式：编辑连接 → 点「清除已保存的密码（仅清除本应用记录，不改动系统凭据）」；也可以
在抽屉里关掉「保存此密码」开关后保存（提示行会写明"关闭开关并保存后才会清除"）。
这一步只删本应用保存的密文，应用里不再显示「已保存」，之后连接需要重新输入密码；
它**不改动 Windows 凭据管理器**——若你曾在 mstsc 里勾过「记住我」，或某次连接走过回退
写入，那些条目仍在，仍可能免密。要清理：开始菜单搜「凭据管理器」→ 用户账户 → 凭据管理器 →
Windows 凭据 → 找到 `TERMSRV/<主机>` 删除。

若保存后连接仍弹登录框，说明系统未采信这组密码，手动输入一次即可。**迁移**：`credentials.json` 的密文与当前 Windows 账户绑定，换机器或重装后无法解密，迁移只需带走 `data.json`（不含密码）。

## 清空所有连接

设置 → 数据与备份 → 「清空全部数据」（需输入确认词 `DELETE`）：

= 删除本应用保存的全部连接与分组、全部已保存密码；进行中的会话会先断开；设置与主题保留；被清掉的主机会加入「已屏蔽的导入记录」，历史导入与备份恢复不会让它们复活（可在同页单条或全部解除屏蔽）
≠ 不动 Windows 凭据管理器：你在 mstsc 里勾过「记住我」的条目全部保留，本应用不读取、不删除、也不写入。
  因此清空后仍可能免密，直到你手动删除该条目。完成后的提示会写明清了几条连接与密码。

## 语言与主题

设置 → 外观：主题 浅色 / 深色 / 跟随系统（默认跟随系统，随 Windows 实时切换）；语言 简体中文 / English / 跟随系统（默认跟随系统）。切换后立即生效。

## 连接状态颜色

| 状态 | 颜色 / 形状 | 含义 |
|---|---|---|
| 已连接 | 绿色实心 | 会话已建立，可从面板断开 |
| 连接中 | 琥珀色（呼吸） | 已启动会话进程（RdpHost / mstsc / FreeRDP），正在等待会话确认 |
| 未建立连接 | 橙色 | 会话进程还活着，但窗口没进桌面——常见于卡在登录框或弹出的错误框 |
| 连接失败 | 红色 | mstsc 启动失败，或进程在会话建立前就退出（地址不通、认证被拒等） |
| 已断开 | 灰色 | 曾连接过，会话已结束 |

卡片上另有一个独立的连通性圆点，只表示 TCP 是否可达，与连接状态是两件事：

- **实心绿点**：在线，后面跟延迟（如「在线 · 18ms」）
- **实心黄点**：离线（含"探测过但没回应"：超时或被防火墙静默丢弃）
- **实心灰点**：从未探测（刚安装、刚启动还没测完）
- **灯很小（6px）、没有外圈**：颜色就是唯一信号，旁边永远有状态文字
- **关掉「自动探测连通性」**：不再按间隔自动出结论，状态回到「未探测」（灰点）；
  顶栏「刷新连通性」仍然可以随时手动探一次。

非 3389 端口会在状态行显示中性徽标（如 `:30389`）。同一台机器不同端口的两条记录，靠这个徽标区分，不需要数地址。

## 活动会话

点顶栏「活动会话」打开右侧面板：列出 RDPilot 管理的会话（名称、地址、PID、开始时间、状态），以及由其他程序打开的 mstsc 窗口（标为「未纳管」，只读展示）。可单个「断开」或「全部断开」；未纳管窗口不受影响。面板打开时定时刷新，连接状态事件也会即时更新。

## 设置与诊断

设置页是一张上下滚动的长页：外观 / 启动与窗口 / 连接与会话 / 数据与备份 / 快捷键 / 关于与诊断依次排列，
不再用横向 Tab 隐藏分节。左侧有可点击的锚点导航，点一下直接跳到对应分节，滚动时也会自动高亮。

- **外观**：主题（跟随系统 / 浅色 / 深色）、语言与界面大小（90% / 100% / 110% / 125%），切换立即生效，不需要重启。界面大小只缩放 RDPilot 主界面，不改变远程桌面分辨率。
- **启动与窗口**：关闭窗口是否最小化到托盘、启动时是否扫描历史、连通性检测与自动探测间隔（30 秒–5 分钟或仅手动）、会话窗口任务栏图标合并/独立、会话窗口是否启动最大化、连接后是否自动识别主机名、导入时是否按网段分组。每一行下面都写了这个开关的副作用。
- **连接与会话**：RDP 协议程序（内置 RdpHost / 系统 mstsc / 随包 FreeRDP / 内嵌主窗口 B2 规划中）、
  没有保存密码时是否使用 Windows 登录凭据、是否跳过远程计算机身份验证警告。
  FreeRDP 可指定本机 `wfreerdp.exe`，留空使用随包组件；它需要保存密码。
- **数据与备份**：
  - **导入历史记录**：从注册表挑选要导入的连接。
  - **导出配置 / 恢复配置**：导出只含连接元数据与设置、不含密码；「恢复配置」从导出的 JSON 合并，已有同键项保持不变。
  - **本地备份**：列出当前 `data.json` 与启动 / 清空 / 恢复前自动生成的滚动备份，可一键恢复；恢复会覆盖当前数据，并在恢复前再自动快照一次（备份不含密码，恢复后需重新输入）。
  - **已屏蔽的导入记录**：删除连接后自动加入，历史导入与备份恢复都会跳过；可单条解除或全部解除，已删除的连接不会自动恢复。
  - **清空全部数据**：危险操作，需输入确认词 `DELETE`；详见上一节。
- **关于与诊断**：版本与运行环境、历史记录读取通道（reg.exe / PowerShell）、状态检测能力、DPAPI 是否可用、已保存密码数量、数据目录与日志目录（可直接复制或打开）、mstsc 路径（可重新检测）、复制诊断信息、恢复默认设置。
- **恢复默认设置**只重置偏好，不删连接与分组。

数据全部在本机 `%APPDATA%\rdpilot\`：`data.json`（连接/分组/设置，不含密码）、`credentials.json`（DPAPI 密文）、`logs\main.log`、`window-state.json`（窗口位置，换机没意义所以不进备份）。便携版不写注册表、不装服务，删掉 exe 即卸载。

## 快捷键

| 按键 | 作用 |
|---|---|
| `F1` | 打开帮助与快速上手（有其它浮层打开时不叠加） |
| `Ctrl + N` | 新建连接 |
| `Ctrl + F` | 聚焦搜索 |
| `Ctrl + A` | 全选当前筛选结果（输入框内仍是全选文本） |
| `Ctrl + Enter` | 连接当前选中（respect 当前筛选，不会连到看不见的主机） |
| `Delete` | 删除选中（多选时删除整批；有确认与撤销） |
| `↑` `↓` | 在列表/卡片间移动焦点 |
| `Enter` | 连接聚焦项；卡片聚焦时 `Space` 等同 `Enter` |
| `F2` | 编辑聚焦项 |
| `Shift + F10` / 菜单键 | 打开右键菜单 |
| `Esc` | 关闭最上层浮层（抽屉、确认框、菜单）；搜索框有关键词时先清空 |
| `双击卡片` / `双击列表行` | 连接（单击只选中；已连接时只选中） |
| `Ctrl + S` / `Ctrl + Shift + S` | 抽屉内保存 / 保存并连接 |
